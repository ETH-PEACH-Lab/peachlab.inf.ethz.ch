14:T54a,Seeing program behavior next to source code can accelerate debugging, learning, and exploration, but most live programming systems deliver this feedback through side-by-side previews or cell-based editor. We present Live in the Editor, an editor-native interaction technique and runtime architecture that turns an ordinary plain-text source file into both program and output surface. Programmers insert lightweight function calls where they want feedback; on save, the system derives execution cells from program structure, incrementally re-executes only changed code and its dependents, and writes outputs back into the file as structured comments adjacent to the relevant code. This text-first design keeps runtime evidence co-located, persistent, and diffable while remaining compatible with existing editors, version-control workflows, and language tooling. Our JavaScript prototype supports the first-class use of asynchronous values, and interactive input controls right in the editor, enabling workflows such as API inspection, debugging, and lightweight textual visualization, and even lightweight textual animation directly in the editor.
